# Контракт путеводителя

`GET /guide/information` возвращает массив с одним объектом `{ cities, photoCredits }`.

- `guide-response.json` — полный пример HTTP-ответа в виде массива.
- `guide.json` — сам объект для записи в одну существующую запись MockAPI. Служебный `id` записи, если он есть, сохраняется на сервере.
- Фотографии лежат в `public/images`. При публикации фронтенда нужно загрузить и эти файлы: `/images/...` — путь относительно домена фронтенда.

## Фотографии места

Добавлено необязательное поле `Place.images: string[]`. Остальные поля сохраняют прежний формат.

```json
{
  "id": "rome-colosseum",
  "name": "Колизей",
  "category": "sights",
  "district": "Celio",
  "description": "Античный амфитеатр с арками и галереями.",
  "image": "/images/rome-colosseum-1.jpg",
  "images": [
    "/images/rome-colosseum-1.jpg",
    "/images/rome-colosseum-2.jpg",
    "/images/rome-colosseum-3.jpg"
  ],
  "tag": "Стоит увидеть",
  "source": "https://colosseo.it/en/"
}
```

`image` — обложка карточки. `images` — полный список фотографий, включая обложку; в подготовленном каталоге у каждого места 2–3 разных снимка. Фронтенд объединяет `image` и `images`, удаляя одинаковые URL. При отсутствии `images` старые записи продолжают показывать одну фотографию. Пустой массив также допустим; элементы должны быть непустыми строками.

`photoCredits` сохраняет формат словаря: ключи уникальные, значение — `{ image, author, license, licenseUrl, source }`. Для новых фотографий ключ имеет вид `<place-id>-<номер>`. Галерея находит подпись по совпадению `credit.image` с URL активного снимка, а не по ID места. Для каждого локального снимка в каталоге есть авторство и лицензия. Фото старых обложек Unsplash сохраняют прежний формат.

Города и страны берутся из ответа автоматически. Новые ID городов и мест уникальны во всём каталоге. Разговорник на каждый день и расширенные местные советы пока доступны для исходных трёх стран; для новых городов используются `phrases` и `tip` из ответа.

Наполнение и снимки можно пересобрать вручную: `node scripts/expand-guide.mjs`. Скрипт обращается к Wikimedia Commons, сохраняет фотографии локально и готовит оба JSON. Он не записывает данные в удалённый API. Кэш запросов находится в `.cache/guide-photos`.
