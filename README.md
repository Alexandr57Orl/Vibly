# Vibly

Путеводитель на React, TypeScript и Vite. Подготовленный каталог включает Москву, Токио, Париж, Рим, Лондон, Стамбул, Барселону, Дубай и Нью-Йорк.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

`build` проверяет типы TypeScript и собирает приложение в `dist`.

## Структура

```text
src/
  api/         # GET-запрос и проверка формата ответа
  components/  # Переиспользуемые элементы интерфейса
  hooks/       # Загрузка данных, фильтрация и сохранение избранного
  pages/       # Страницы приложения
  data/        # Подписи категорий интерфейса
  types/       # Общие типы
  styles.css   # Адаптивные стили
  main.tsx     # Точка входа
```

## Возможности

- Выбор страны и города из ответа API.
- Поиск по названию, району и описанию, фильтрация по категориям.
- Избранное из всех городов с сохранением в `localStorage`.
- Подробности места, галерея фотографий с миниатюрами, стрелками, клавиатурой и свайпом, ссылки на карту и сайт источника.
- Местные выражения и советы для каждого города.
- Подборки «Первое знакомство», «Кофе и прогулка» и «Освоиться в городе» на основе категорий мест.
- План прогулки до четырёх остановок: добавление из карточек, изменение порядка, удаление и сохранение отдельно для каждого города в текущем браузере.
- Пешеходный маршрут из плана открывается в Google Maps; расстояние и время рассчитывает карта, порядок остановок задаёт пользователь.
- Компактная шапка с выбором города и избранным, вкладки «Места» и «Разговорник».
- План открывается в боковой панели на компьютере и в панели снизу на телефоне. Мобильная кнопка плана всегда доступна.
- Копирование местных фраз; подборки по настроению доступны под кнопкой фильтров рядом с поиском.
- Практичный разговорник: по шесть фраз для России, Японии и Франции, ситуации общения, перевод и приблизительное произношение кириллицей. Местные выражения доступны отдельно.
- Озвучка через Web Speech API при наличии голоса нужного языка на устройстве; без подходящего голоса остаются текст и произношение. Аудиофайлы и платные API не используются.
- Адаптивная вёрстка, клавиатурная навигация, модальные окна с удержанием фокуса.

## API

Путеводитель загружается одним GET-запросом при открытии страницы:

```text
https://6aec88e1fc3b911e6fd54a2f.mockapi.io/api/v1/guide/information
```

Сервис возвращает массив с одним объектом `{ cities, photoCredits }`. Новый полный ответ сохранён в `docs/guide-response.json` (9 городов, 46 мест, по 2–3 фотографии). Объект одной записи MockAPI находится в `docs/guide.json`. Это образцы для наполнения API; приложение не использует их как локальный источник данных. Для появления нового каталога обновите существующую запись сервера объектом из `docs/guide.json` и перезагрузите страницу. Код не записывает данные в удалённый API.

Контракт и пример нового поля `Place.images` описаны в `docs/guide-contract.md`. Обложка по-прежнему задаётся через `image`; старые ответы без `images` совместимы. Подпись автора и лицензия меняются вместе с выбранным снимком. При размещении фронтенда публикуйте всю папку `public/images`.

Проверка контракта, обратной совместимости и локальных файлов фотографий: `node scripts/verify-guide.mjs`.

Для другого адреса создай `.env.local` по образцу `.env.example`, укажи `VITE_GUIDE_API_URL` и перезапусти Vite. Переменные с префиксом `VITE_` доступны в браузере, поэтому секреты в них хранить нельзя.

Для добавления города обнови ответ сервера, добавив объект типа `City` с уникальными ID города и мест. Список стран и доступных городов формируется из ответа автоматически. Поиск, фильтры и переключение городов выполняются в браузере без дополнительных запросов. Для получения изменений с сервера перезагрузи страницу.

При загрузке отображается индикатор. При сетевой ошибке, некорректном или пустом ответе показывается сообщение с кнопкой повторной попытки. Запрос отменяется при уходе со страницы или после 15 секунд ожидания.

Фотографии мест из Wikimedia Commons хранятся в `public/images`; авторы, лицензии и ссылки на оригиналы загружаются в поле `photoCredits` ответа API и отображаются в подробностях карточек. Пути `/images/...` относятся к домену фронтенда. Фотографии обложек загружаются с Unsplash, шрифты — с Google Fonts. Для загрузки данных и внешних ресурсов нужен интернет. Избранное доступно только в текущем браузере; при недоступном хранилище оно работает в памяти до перезагрузки.

Перед посещением проверяйте расписание, билеты и условия на сайтах мест. Приложение не обновляет эти сведения автоматически.

Планы хранятся под ключом `vibly-trip-plan`. Если браузер запрещает запись, план продолжает работать до закрытия страницы, а интерфейс сообщает об ограничении. Подборки не гарантируют определённую длительность, доступность или стоимость посещения: этих данных в API пока нет. Копирование фраз требует доступа к буферу обмена и защищённого контекста (HTTPS или localhost).

## Языки интерфейса

Доступны RU и EN. Переключатель находится в шапке, включая экран загрузки и ошибок. При первом открытии русский выбирается для русскоязычного браузера, английский — для остальных. Выбор сохраняется в `localStorage` под ключом `vibly-language`.

`src/i18n/index.tsx` содержит провайдер и хук `useI18n()`. Для вывода текста используй `t("Русский текст")`; английский вариант добавляй в `src/i18n/en.json`. Русские строки служат ключами словаря. Если перевод отсутствует, отображается исходный текст. При изменении русского текста нужно обновить соответствующий ключ.

Словарь включает текущие города, места, советы, переводы фраз и подсказки произношения. Новые или изменённые тексты из API нужно добавлять в словарь: автоматического перевода нет. Фразы для собеседника остаются на языке страны; перевод, пояснения и произношение следуют языку интерфейса. Поиск учитывает исходные тексты и их переводы. Смена языка не меняет ID, избранное и планы прогулок.

## Советы местных

Вкладка «Советы местных» находится рядом с «Местами» и «Разговорником». Для Москвы, Токио и Парижа добавлено по шесть карточек: переходы и дорожное движение, транспорт, этикет и кафе. Советы фильтруются по теме; в карточках отдельно помечены правила, привычки и практические рекомендации. Прежний `city.tip` перенесён из разговорника в начало новой вкладки.

Материалы находятся в `src/data/localAdvice.ts`, привязка — по ID города. У каждой карточки есть ссылка на источник; `adviceReviewedAt` — дата редакторской проверки ссылок и сведений, а не дата автоматического обновления. После проверки меняйте её вручную. Новые тексты и подписи источников добавляйте также в `src/i18n/en.json`. Для города без подборки показывается его `city.tip`, без чужих советов и отметки проверки.

Лента направлений занимает один ряд: на компьютере видны три карточки, на телефоне — одна и часть следующей. Остальные направления доступны через горизонтальную прокрутку, стрелки и точки навигации. Лента автоматически перелистывается каждые 4,5 секунды, когда карточки не помещаются по ширине; есть кнопка паузы. Наведение, фокус клавиатуры, касание, открытая модальная панель, скрытая вкладка и уход ленты за пределы экрана приостанавливают движение. После ручного взаимодействия выдерживается пауза; при `prefers-reduced-motion` автоматическое движение отключено. Прокрутка не переключает выбранный город.

## Открытия сообщества (демо)

Вкладка «Открытия сообщества» показывает предложения для выбранного города. Чтобы добавить место, нужно пройти демонстрационный вход или регистрацию; после этого открывается форма с названием, адресом и описанием. Это интерфейсная заглушка: аккаунты не создаются и не проверяются, подходят вымышленные данные и любой тестовый пароль от 6 символов. Пароль нигде не сохраняется и не отправляется.

Демопрофиль хранится в `sessionStorage` (`vibly-demo-user`), предложения — в `localStorage` (`vibly-community-places`). Они доступны только в этом браузере, не попадают в основной каталог и не публикуются для других пользователей. Выход удаляет демосессию, сохраняя предложения. Тексты поддерживают RU/EN, оформление — светлую и тёмную темы. Для настоящей регистрации и общей ленты потребуется подключение бэкенда с серверной проверкой доступа.

К предложению можно прикрепить одно фото JPG, PNG или WebP до 10 МБ, заменить или удалить его перед добавлением. Фото уменьшается до 1280 пикселей по длинной стороне и сохраняется в формате JPEG вместе с предложением. Старые предложения без фото поддерживаются. Если место в хранилище закончилось, интерфейс сообщает, что новое предложение доступно только до перезагрузки.
